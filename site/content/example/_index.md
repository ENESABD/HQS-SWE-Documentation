**See It All in Action**

The **GiftList API** is a REST API built with Laravel that demonstrates how the concepts from this guide come together in a real project. It's a simple gift tracking application—but simple is the point. The code is readable, the architecture is clean, and the framework does the heavy lifting.

## Technology Stack

- **Laravel 12** (PHP 8.2+) — High-level framework
- **Eloquent ORM** — Database abstraction
- **MySQL** — Relational database
- **Laravel Sanctum** — API authentication
- **PHPUnit** — Testing

## What This Section Covers

- **Why Laravel?** — How the framework solves common problems
- **The ORM in Action** — Eloquent replacing raw SQL
- **API Architecture** — MVC, routing, and REST design
